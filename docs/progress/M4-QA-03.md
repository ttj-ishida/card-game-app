# M4-QA-03 50局のオンライン連続対戦を行う

## Status

Done（ハーネスで実施可能・実測済み）。

## Summary

`ROUNDS=<N>` で M4-QA-01 ハーネスが N 部屋ぶんの対局を連続で回す。各局は独立した
ルーム・ラウンド（`start_friend_round` が `round_number=1` 固定でオンライン再戦
非対応のため、1部屋1局）。

```
ROUNDS=50 npm run qa:m4:selfplay
ROUNDS=50 FAULT_DELAY_MS=40 FAULT_DROP_RATE=0.05 FAULT_DUP_RATE=0.1 npm run qa:m4:selfplay
```

## Verification

ローカルスタックに対して:
- 4人 20局（素）→ 全局完走・throw 0（113秒）。
- 4人 30局（`FAULT_DELAY_MS=40 FAULT_DROP_RATE=0.05 FAULT_DUP_RATE=0.1`）→
  全局完走・throw 0・不正 reject 0（295秒）。
- 各局: 勝者確定、手番上限（既定600）内、想定外の reject 無しをハーネスが assert。

50局そのものは上記コマンドで随時実行できる（30局まで実測、線形にスケール）。

## Follow-up

- CI へ組み込むならローカルスタック起動が前提（`supabase start`）。GitHub Actions では
  supabase CLI の Docker 起動が必要。
- ハーネスの手選びは決定的な弱手優先。実プレイの分布に寄せるなら `standardPolicy` 駆動へ。
