# M4-SB-12: フレンド対戦の退出・棄権・任意CPU引継ぎ

## 状態

完了。

## 実装内容

- 対局中退出RPC `leave_friend_round(round_id, requested_cpu_takeover)` を追加した。
- `requested_cpu_takeover = true` かつルーム設定でCPU引継ぎが有効な場合、退出者の対局席を `CPU_TAKEOVER` / `CPU` に変更し、局は継続する。
- CPU引継ぎを使わない場合は棄権として扱い、退出者の手札を破棄して `OUT` にする。2人戦では残ったプレイヤーを勝者にし、局を `COMPLETED` にする。
- どちらの経路でも `online_round_events` に公開イベントを追加し、`state_version` を進める。
- DBテスト `online_round_leave.sql` を追加し、CPU引継ぎ、棄権、非参加者拒否を検証した。
