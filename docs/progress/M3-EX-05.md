# M3-EX-05: CPU戦統計画面

## 状態

完了。CPU練習結果の集計RPCを読み取り、`/cpu-game/stats` で対局数、勝利数、勝率、最終対局時刻を確認できる。

## 実装

- `apps/mobile/src/features/cpu-game/statsModel.ts`
  - `get_player_mode_stats` RPC を `anon_player_id` と `CPU_PRACTICE` で呼び出す。
  - 0件または勝率なしは空状態として扱う。
- `apps/mobile/src/state/cpuGameStatsStore.ts`
  - 匿名IDと Supabase RPC 依存を注入して統計をロード。
- `apps/mobile/src/app/cpu-game/stats.tsx`
  - 読み込み中、空、失敗、統計表示に対応。
- `apps/mobile/src/app/_layout.tsx` / `apps/mobile/src/app/cpu-game/setup.tsx`
  - ルート定義と CPU戦セットアップ画面からの導線を追加。
