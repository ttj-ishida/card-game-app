## メモ

- **boardViewModel の契約** — `DriverState` + `selection` + `legalPlays` → `BoardViewModel`（全表示データ）。型・値変換は完全に純粋関数。画面は `BoardViewModel` を描画し、ユーザー入力は `cpuGameStore` のアクション（`selectCard` 等）へ導く。
- **CardFace の役割** — 唯一のカード描画コンポーネント。入力は `{ rank, suitCode, isJoker, size: 'hand' | 'field' | 'mini' }`。M2 は「数字 + 属性色（火=赤、水=青、風=緑、土=黄） + 属性ラベル（日本語）+ 形状/記号」を描画（デフォルトパック）。M3 で複数パック対応時に `packId` パラメータを足すだけで自動対応。
- **手札構成** — 2 人配布で 18 枚、6 人配布で 6 枚（game-core の `dealRound` で保証）。ビューモデルが `(rank, suitCode)` の昇順でソート。
- **相手パネル** — 人間席（seat-0）を除く全席を席順で表示。各席に「枚数」「スキル有無」「ステータス（ACTIVE/PASSED/OUT）」「手番フォーカス」を表示。
- **場表示** — 最初は null、リード後に `FieldView`（カード列 + 種別 + 最後の出し手）に。ロック 3 行（枚数ロック● / 属性固定[火] / 属性統一—）と追加封印— を別フィールドで表示（UI-BATTLE-005）。
- **強弱順** — 昼 [1..9]、夜 [9..1]。昼夜遷移は `game-core` の `revolutionCondition()` で完全に決定的（UI は `dayNight` を反映するだけ）。
