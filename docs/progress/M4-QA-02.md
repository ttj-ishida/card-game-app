# M4-QA-02 遅延・重複・順序入替・切断を注入する

## Status

Done。M4-QA-01 のハーネス（`apps/mobile/scripts/online-self-play.ts`）を拡張。

## Summary

`OnlineHttpPort` の実体に障害注入を仕込み、対局ループ中（ルーム作成・参加・開始は素通し）だけ有効化する:

- `FAULT_DELAY_MS`: 各リクエスト前に 0..N ミリ秒のランダム遅延。
- `FAULT_DROP_RATE`: 各リクエストを確率 p で失敗させる（切断相当）。GET/POST 双方。
- `FAULT_DUP_RATE`: 各 POST を確率 p で二重送信（`request_id` 固定なので冪等性
  M4-SB-08 のテストになる）。

対応するクライアント側の回復:
- `withRetry()` — 切断相当のエラーだけ最大6回まで飲み込んでスナップショット取得等を再試行。
- `submitWithRetry()` — 同一 `request_id` で最大5回。`STALE_STATE_VERSION` が返れば
  「直前の試行が実は届いていた／他クライアントが動いた」として前進扱い。

順序入替は、複数クライアントの手番判定＋`expected_state_version` ガードで実質的にカバー
（古い版で投げると `STALE_STATE_VERSION` で弾かれる）。

## Verification

ローカルスタックに対して:
- `FAULT_DELAY_MS=100 FAULT_DROP_RATE=0.15 FAULT_DUP_RATE=0.25` で 3人3局 → 全局完走。
- 併用: `FAULT_DROP_RATE=0.1 FAULT_DUP_RATE=0.15 FORFEIT_AT=10` で 5人1局 → 完走。
