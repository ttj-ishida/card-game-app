## 概要

パス、通常の場流し、上がり、禁止上がりの判定ヘルパーを `game-core` に純粋関数として追加した。いずれも不変の入力から結果を計算し、状態の書き換えや物理的なカード移動は行わない（M1-EX-09 で状態適用と一緒に扱う）。

## 追加した関数

| 関数                  | 役割                                                                 | 対応要件 |
| --------------------- | ------------------------------------------------------------------- | -------- |
| `evaluatePass`        | 場がある場合のみパスを合法とし、連続パス数と場流し発火を返す        | TURN-002 / TURN-005 / FLOW-001 / T-RULE-019 |
| `resolveFieldClear`   | アクティブセットの捨て札移動、属性ロック・追加封印の解除、昼夜維持、次の先頭決定 | FLOW-002〜006 / LOCK-005 / SEAL-007 / DAYNIGHT-001 |
| `evaluateGoOut`       | 全効果処理後に数字カード0枚で上がり。変化Jokerを含むプレイの上がりは禁止 | WIN-001 / WIN-003〜007 / WIN-008 / JTR-009 |
| `determineRoundWinner`| 数字カードを最初に0枚にしたプレイヤーを勝者として返す              | WIN-101 |

## メモ

- `evaluatePass` の `mustLead` は場流しJoker継続中（JCLR-007）のパス禁止を表す。呼び出し側が `evaluateJokerClear` の `mustLead` を渡す想定。
- 場流し発火条件は「最終出し手が現在もアクティブなら アクティブ人数 − 1 人、棄権・上がり済みなら アクティブ人数」の連続パスで判定する。
- `resolveFieldClear` の `fallbackLeaderId` は FLOW-006 用に、最終出し手が不在のときの手番順で次のアクティブプレイヤーを呼び出し側が渡す。
- 棄権（FORFEIT-*）は §19 の通信・切断系であり M1 のローカル・ルールサンドボックス範囲外と判断した。残り1人勝利（FORFEIT-008）は後続マイルストーンで `determineRoundWinner` を拡張して扱う。
- 連続パスのリセット（TURN-003）と最終出し手の記録は M1-EX-09 の状態適用で行う。
