# M3-GR-01: 役職キャラクター粗イラスト

## 状態

完了。M3 Alpha向けの仮置きSVGとして、1〜9位の役職イラストを生成した。

## 実装

- `scripts/generate-m3-graphics-assets.mjs`
  - 1〜9位の役職ごとに、色・シルエット・大きな順位番号を持つ編集可能なSVGを生成。
  - `assets/source/m3/card-illustrations/*.source.svg` と `assets/runtime/m3/card-illustrations/*.svg` を同一内容で出力。
- `assets/manifests/m3-graphics-assets.json`
  - `rankIllustrations` に全9件の assetId、sourcePath、runtimePath、rankCode、表示名、サイズ定義を登録。

## 確認

- `npm run assets:generate:m3`
- `npm run assets:check:m3`

## 残り

- 本番向けの画作りでは、外部イラストまたは描き起こし素材に差し替える。
- M3-QAでは、実UIに載せたときの小サイズ可読性を確認する。
