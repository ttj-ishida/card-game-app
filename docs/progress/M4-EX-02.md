## 追記（2026-09-07）: 招待コードのエラー処理

- `create_friend_room` が使用済み招待コードで一意制約違反（23505）をそのまま漏らしていた
  → `P0001 'INVITE_CODE_TAKEN'` として返すマイグレーション `20260907090000_*` を適用・**本番反映済み**
  （本番で user1 作成 → user2 同コード → `{"code":"P0001","message":"INVITE_CODE_TAKEN"}` を確認）。
- クライアント: `OnlineRoomRpcError` でサーバーメッセージを保持し、ストアが
  `INVITE_CODE_TAKEN` / `room not found` / `room is full` / `room is not waiting` を専用文言へ。
- 招待コードは英数字4〜16文字（`isValidInviteCode`）。不正なコードはネットワーク前に弾く。
  入力欄も `maxLength=16`。
- **要新ビルド**: クライアント側の文言・バリデーションは現行APK（`06929559`）に未反映。

## 追記（2026-09-07）: 着地ページの環境別分岐

`/join?code=CODE` を開いた環境で挙動を分ける（`resolveJoinTarget` 純関数、テスト5件）:

| 環境 | 挙動 |
|---|---|
| ネイティブアプリ内 / デスクトップWeb | そのまま参加画面 `/online-room?invite=CODE` へ（Web はブラウザでそのまま対戦できる） |
| スマホのブラウザ（＝アプリ未導入の可能性大） | 「Google Play で入手」/「アプリで開く」（カスタムスキーム）/「このままブラウザで参加」を提示 |

- UA 判定はクライアントJS側（SPA）。curl では静的シェルしか見えないが、実ブラウザで分岐する。
- Google Play URL は `?id=com.ttjishida.ragnarokmillennium`（公開までは 404 になる）。
- **iOS**: `APP_STORE_URL = null`（iOS版未提供）。Universal Links を有効にするには将来
  `ios.bundleIdentifier` + `ios.associatedDomains: ["applinks:card-game-app.expo.app"]` +
  `public/.well-known/apple-app-site-association`（Apple Team ID 必要）を追加し iOS ビルドする。
