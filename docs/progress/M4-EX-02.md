## 残りチェックリスト

1. **Web を EAS Hosting へデプロイ**
   ```bash
   cd apps/mobile
   npx eas deploy --prod
   ```
   → 公開URL（`https://<something>.expo.app`）が出る。**公開デプロイなので実行前に要確認。**
   - slug が `card-game-app` のため、デフォルトドメインは `card-game-app.expo.app` 想定。
     別名にしたい場合は `--alias ragnarok-millennium`、独自ドメインは EAS の有料プラン。
   - デプロイ後、実際のホストが `app.json` の `intentFilters` の host と一致しているか確認。
     違えば app.json を直して再ビルドが必要。

2. **`assetlinks.json` を用意**
   - まず `https://<host>/.well-known/assetlinks.json` を開く。Expo が自動生成していれば完了。
   - 無ければ `apps/mobile/public/.well-known/assetlinks.json` を作成（README のテンプレ）。
     SHA-256 は Expo ダッシュボード（Project → Credentials → Android）または
     `eas credentials --platform android` から取得。→ 再デプロイ。

3. **App Link 設定込みで Android を再ビルド**
   `intentFilters` はネイティブ設定なので、現行の APK には入っていない。
   ```bash
   cd apps/mobile
   npx eas build --platform android --profile preview
   ```

4. **実機検証**
   - 導入済み端末で `https://<host>/join/ROOM123` をタップ → アプリが直接開き、
     招待コードが入っていること（Android の App Links 検証には数分かかることがある）。
   - 未導入端末（or PC）で同じURL → Web 案内ページが表示されること。
   - アプリ内の「招待リンクを共有」で正しい文面が共有シートに出ること。
