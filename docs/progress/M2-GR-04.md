## 概要

カード選択・提出・勝利の基本演出素材のプレースホルダ SVG をプログラム生成で追加した（M1-GR 方式踏襲）。形と向きで区別。仮アニメーションへ適用できる静的SVGフレーム。本番アートは M3-GR / M6 で差し替える。

| 種別 | パス |
| --- | --- |
| 生成物 | `m2-fx-select`（選択ハイライト枠）/ `m2-fx-submit`（提出バースト）/ `m2-fx-victory`（勝利バナー） |
| source | `assets/source/m2/battle/` |
| runtime | `assets/runtime/m2/battle/` |
| manifest | `assets/manifests/m2-battle-assets.json` |
| 生成script | `scripts/generate-m2-battle-assets.mjs` |
| 検査script | `scripts/check-m2-assets.mjs` |

## 確認

| コマンド | 結果 |
| --- | --- |

## メモ

- 色に依存せず形・シルエットで意味を持たせる（UI-A11Y-001/002）。
- モバイルアプリのコードは変更なし。画面配線（背景・`CardFace` のフレーム/紋章/イラスト・演出レイヤ）は M3 以降の演出実装で、`MatchConfig.packId` をパック切替の継ぎ目とする。
