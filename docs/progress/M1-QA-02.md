## 概要

シード付き乱数で `RoundState` と最大60手のプレイ列を生成し、`resolvePlay()` を適用しながら状態不変条件を毎手検査するプロパティテストを追加した。カード重複・枚数消失・二重消費・不正時の部分更新が起きないことを保証する。

## 成果物

| 種別 | パス                                            |
| ---- | --------------------------------------------- |
| test | `packages/game-core/src/stateInvariants.test.ts` |

## 検査する不変条件

- 実在数字カード（変化Joker由来の合成カードを除く）の ID 集合が、配布した山と毎手完全一致する（枚数消失・複製なし）。
- カード ID の重複が全ゾーン（手札・場・捨て札）を通じて発生しない。
- `activePlayerId` が実在プレイヤーを指す。`dayNight` が `DAY`/`NIGHT`。`consecutivePasses >= 0`。
- 使用済みスキル数は単調非減少（二重消費・使用取消なし）。
- 不正なプレイは同一参照を返し、状態がバイト単位で不変（`structuredClone` 比較）。
- 勝者が出たら当該プレイヤーは `status: "OUT"`。

## 実行構成

- 25 シード × 60 手、各手で全不変条件を検査。
- 固定シードのためテストは決定的。`4242` シードで走査トレースが 2 回実行で完全一致することを別テストで確認（再現性）。

## メモ

- 乱数プレイ生成器は PASS / 数字プレイ / 追加封印 / 革命 / 場流しJoker を混ぜる。変化Joker宣言（`JOKER_TRANSFORM`）は合成カードを場に持ち込むため山との一致検査を単純化する目的で除外し、実カード ID の保存だけを検査対象にする。宣言重複や変化Joker上がり禁止は M1-QA-01 と単体テストで担保済み。
- 失敗ケースの保存（確認方法）は、失敗時に seed が判明するテスト名（`seed N`）で再現できる。
