# M4-EX-04: オンライン対局状態をローカル表示状態へ変換する

## Status

Done.

## Summary

Supabase の `get_friend_round_snapshot` RPC が返すオンライン対局 snapshot を、mobile 側の表示に使える `OnlineRoundViewModel` へ変換する純モジュールを追加した。

## Deliverables

- `apps/mobile/src/features/online-room/onlineRoundViewModel.ts`
  - `public_state.active_field` を field / lock 表示へ変換。
  - 本人手札 `hand` を `HandCardView[]` へ変換。
  - 本人スキル `skills` を seed の skill id から効果コードへ変換。
  - 公開 `events` を表示用イベントへ変換。
  - `hand_counts` の key が player id / seat index のどちらでも、公開相手 count として保持。
- `apps/mobile/src/features/online-room/onlineRoomClient.ts`
  - `fetchOnlineRoundSnapshot(roundId, afterStateVersion, deps)` を追加。
- `apps/mobile/src/features/online-room/onlineRoundViewModel.test.ts`
  - 手札 card id パース、スキル id パース、場・ロック・イベント・相手 count 変換を確認。

## Verification

| --- | --- |
| `npm exec -- tsx src/features/online-room/onlineRoomClient.test.ts` | PASS |
| `npm exec -- tsx src/features/online-room/onlineRoundViewModel.test.ts` | PASS |
| `npm run mobile:typecheck` | PASS |

## Notes

- 現在の snapshot RPC は本人手札に `card_id` だけを返すため、M0 seed の安定 card id（例 `CARD_NUMBER_RANK_7_SUIT_WIND`）から rank / suit を復元している。
- 後続で RPC が rank / suit を直接返すようになった場合も、この変換層だけを差し替えれば画面側の契約を保てる。
