## 実装内容

- `commit_friend_play(...)` DB関数を追加した。
  - `online_round_public_state` と `rounds` を `FOR UPDATE` でロックし、現在の `state_version` と `expected_state_version` が一致する場合だけ更新する。
  - 成立時は手札、スキル消費、公開状態、roundsの状態版、公開イベントを1つのPostgres関数内で更新する。
  - 状態版不一致時は `STALE_STATE_VERSION` を返し、手札・公開状態・イベントを変更しない。
- `submit-play` Edge Functionを更新し、共有ルール検証に成功した要求を `commit_friend_play` へ渡して永続化するようにした。
