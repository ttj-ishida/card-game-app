## メモ

- 描画は View/Text とデザイントークン（M0-QA-01 踏襲、`react-native-svg` 不要）。属性・状態は色＋文字ラベルで判別。
- 変化Joker宣言は1手番1枚に限定（1プレイヤー＝スキル1枚のモデル制約）。
- 変化Joker由来のカード（`isTransformedJokerCard`）は `CardChip` に「J」バッジと読み上げ用サフィックス（`sandbox.card.joker`）を付与。実カードの見た目は不変。
- `translate.test.ts` の reason 網羅は `satisfies Record<PlayRejectionReason, true>` の `REASON_CODES` マップに変更し、game-core が reason を追加すると `tsc` が失敗するようにした。
- プリセットは QA-03 チェックリストの代表10件。残りの T-RULE ケース追加は軽微な後続作業。
- 実機での横画面・文字拡大・読み上げ順の目視確認は別途「実機確認記録」として実施する。
- `packages/*` の解決は `metro.config.js` と `tsconfig.json` の `paths` のみで行い、`apps/mobile/package.json` / `package-lock.json` は不変。
- `packages/ui/src/index.ts` は `./tokens.js` を再エクスポートするため、Metro が TS ソースを解決できない。`metro.config.js` に `config.resolver.resolveRequest` シムを追加し、`@card-game-app/ui` を `packages/ui/src/tokens.ts`（全エクスポート保持）へ直接向けた。既定リゾルバへの委譲は維持。あわせて `tsconfig.json` の `@card-game-app/ui` パスも `packages/ui/src/tokens.ts` に合わせ、tsc と Metro が同一ファイルを解決するようにした（バレル `index.ts` の `.js` 再エクスポートという潜在的な地雷を除去）。
- 場のカード列はストアの `fieldDraft`（`{ cards: NumberCard[]; lastPlayerId: string }`）で編集し、`isValidFieldCards` が真のときだけ `commitFieldDraft` が `setFieldCards` で`draft`へ反映する。無効な列は反映せず警告表示のみ。`commitFieldDraft` は `lastPlayerId` が現在のプレイヤーでなければ `players[0]` にクランプする（人数減少後の幽霊プレイヤー混入を防止）。コミット後は `fieldDraft.cards` を空へ戻す。
