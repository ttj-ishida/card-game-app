## 概要

対局結果の保存と二重登録防止。`practiceResultSync` モジュール（HTTP POST）で Supabase へ保存。一時的失敗（5xx・ネットワーク例外）は `practiceResultQueue` へ退避し、アプリ起動時・アプリ前面復帰時（`AppState` 'active'）・対局終了ごとに `flushPracticeResultQueue()` で再送。恒久的失敗（その他 4xx＝不正ペイロード / 失効キー / CHECK 違反）は `'rejected'` として退避せず、結果画面に「保存できませんでした」を表示。`client_result_id` で冪等性を保証。キューは 100 件で頭打ち（古い方から破棄）。

## メモ

- **savePracticeResult** — POST `/rest/v1/practice_round_results`。200/201/204 → `'saved'` / 409 or unique 違反 (23505 / duplicate key) → `'duplicate'` / その他 4xx → `'rejected'`（恒久的、再送しない）/ 5xx・例外 → `'failed'`（一時的、再送する）。HTTP port 注入で実体を配線。
- **enqueuePracticeResult** — 一時的失敗時に `QUEUE_KEY` をキーとする JSON 配列へ退避。`client_result_id` で重複排除。上限 100 件（`MAX_QUEUE`）、超過分は先頭から破棄。
- **flushPracticeResultQueue** — キューを順に save。saved / duplicate / rejected は除去、failed だけ残す。返り値は `{ flushed: 数, remaining: 数 }`（`flushed` は除去合計）。空キューは即 `{0,0}` で return。
- **recordFinishedRound** — オーケストレータ。save 試行 → `'failed'` のときだけ enqueue（`'rejected'` は退避しない）。最終ステータスを返す。
- **呼び出し** — `finishRound`（ストア）が `recordFinishedRound` を対局終了時に1回呼び、完了後に `flushQueue()` を fire-and-forget。`flushQueue` アクションはさらに `_layout.tsx` の `useEffect` からアプリ起動時＋`AppState` 'active' で呼ばれる。`flushQueue` は未設定時 no-op、エラーは常に握り潰す（`saveStatus` は触らない）。
- **saveStatus マッピング**（`finishRound`）— `'saved'`→`saved` / `'duplicate'`→`duplicate` / `'failed'`（退避済み）→`queued` / `'rejected'`（恒久的）→`failed` / 例外 catch →`queued`。
- **二重登録防止** — `client_result_id` を対局終了時に `makeId()` で生成しストア（`cpuGameStore` state の `clientResultId`）に保持。再送で同じ値を使う。DB 側も unique 制約。

## テーブル

### practiceResultSync テスト

| テスト | 対象 | 検証内容 |
| --- | --- | --- |
| 200/201/204 → saved | 成功時 | ステータス 'saved' |
| 409 / unique 違反 → duplicate | 重複検知 | ステータス 'duplicate' |
| その他 4xx (400/401/422) → rejected | 恒久的失敗 | ステータス 'rejected'、退避しない |
| 5xx・ネットワーク例外 → failed | 一時的失敗 | ステータス 'failed'、退避する |

### practiceResultQueue テスト（`practiceResultSync.test.ts` に同居）

| テスト | 対象 | 検証内容 |
| --- | --- | --- |
| enqueuePracticeResult | 退避 | キーに JSON 配列、重複排除、100 件上限 |
| flushPracticeResultQueue | 再送 | saved/duplicate/rejected 除去、failed 残す |
| recordFinishedRound | オーケストレーション | failed→enqueue、rejected→退避しない |

## 将来への申し送り
