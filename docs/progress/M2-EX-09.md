## 概要

対局結果の保存と二重登録防止。`practiceResultSync` モジュール（HTTP POST）で Supabase へ保存。失敗時は `practiceResultQueue` へ退避し、アプリ再起動後・対局終了ごと・定期的に `flushPracticeResultQueue()` で再送。`client_result_id` で冪等性を保証。

## メモ

- **savePracticeResult** — POST `/rest/v1/practice_round_results`。201 → `'saved'` / 409 or unique 違反 (23505) → `'duplicate'` / それ以外 → `'failed'`。HTTP port 注入で実体を配線。
- **enqueuePracticeResult** — 失敗時に `QUEUE_KEY` をキーとする JSON 配列へ退避。`client_result_id` で重複排除。
- **flushPracticeResultQueue** — キューを順に save。saved / duplicate は除去、failed は残す。返り値は `{ flushed: 数, remaining: 数 }`。
- **recordFinishedRound** — オーケストレータ。save 試行 → failed なら enqueue。最終ステータスを返す。結果画面から呼び出し（1回のみ）。
- **呼び出し** — `recordFinishedRound` は結果画面到達時に1回。`flushPracticeResultQueue` はアプリ前面復帰時（`AppState` 'active'）＋対局終了ごと。
- **二重登録防止** — `client_result_id` を対局終了時に生成し `DriverState` / `RoundResultView` に保持。再送で同じ値を使う。DB 側も unique 制約。
