# M3-GR-02: 属性フレーム・属性アイコン粗素材

## 状態

完了。火・水・風・土の4属性について、色だけに依存しないフレームとエンブレムを生成した。

## 実装

- `scripts/generate-m3-graphics-assets.mjs`
  - 属性ごとに shape cue を分けたフレームSVGを生成。
    - 火: spikes
    - 水: waves
    - 風: swirls
    - 土: diamonds
  - 同じ4属性の小型エンブレムSVGを生成。
  - source/runtime の両方に出力。
- `assets/manifests/m3-graphics-assets.json`
  - `attributeFrames` 4件と `attributeEmblems` 4件を登録。

## 確認

- `npm run assets:generate:m3`
- `npm run assets:check:m3`
