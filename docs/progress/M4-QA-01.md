## Summary

`apps/mobile/scripts/online-self-play.ts` + npm script `qa:m4:selfplay`。

- 実クライアント関数（`onlineRoomClient.ts` の `createOnlineRoom` / `joinOnlineRoom` /
  `startOnlineRound` / `fetchOnlineRoundSnapshot` / `submitOnlinePlayRequest`）を
  そのまま使い、各シミュレートクライアントに独立した匿名セッション（in-memory storage）を
  持たせる。`fetch` ベースの `OnlineHttpPort` 実体。
- 手番判定は代表クライアントのスナップショット、着手は `buildRoundStateForLegalMoves`
  （M4-EX-05 の合法手ヘルパ）→ `enumerateLegalPlays(state, { includeSkills: true })`
  → 決定的な手選び（上がれるなら上がる → 素の最弱手 → PASS）。
- `STALE_STATE_VERSION` は次ループで取り直し。決着（イベントの `winner_id` /
  `submit-play` の `outcome.winner_id`）まで回して、勝者確定・手番上限内・
  想定外の reject が無いことを検証する。
- 環境変数: `PLAYERS`（2〜6）/ `ROUNDS`（連続部屋数、QA-03 は `ROUNDS=50`）/
  `MAX_TURNS` / `POLL_MS` / `VERBOSE` / `SUPABASE_URL` / `SUPABASE_ANON_KEY`。
  既定はローカルスタック。

## 発見・修正したバグ

**`submit-play` が JOKER_TRANSFORM のプレイで 500 クラッシュ**（本番既存、今回修正）。
`packages/game-core/src/serverRequest.ts` の `isValidJokerDeclarations` が
`declaration.asCardId.length` を参照していたが、`JokerDeclaration` 型に `asCardId` は
無く（`{ skillId, rankCode, suitCode }` のみ）、`undefined.length` で TypeError → 500。
`serverRequest.ts` は `game-core` の `tsconfig.json`（`include: ["src/index.ts"]`）から
外れていて型検査されておらず、Deno 側の型検査もローカル未実行だったため見逃されていた。

- 修正: `isValidJokerDeclarations` を実際の型（skillId/rankCode/suitCode）で検証。
- 再発防止: `packages/game-core/tsconfig.json` の include に `src/server.ts` を追加。
- テスト: `serverRequest.test.ts` に整形式 JOKER_TRANSFORM エンベロープが
  `INVALID_REQUEST` を返さず throw もしないことを確認するテストを追加。
- **要 `supabase functions deploy submit-play`**（本番反映）。
