- Status: DONE
- Completed: 2026-08-28
- Owner: Project owner
- Related decision: ADR-0002

## 実施内容

- `npx supabase init`でSupabaseローカル構成を初期化した。
- `supabase/config.toml`を作成し、ローカルDB、API、Studio、Auth、Storage、Realtimeの標準設定を導入した。
- `development`用Supabaseプロジェクト`evzmtxwdsoebekxlqxeo`へ`supabase link`した。
- マイグレーション、Edge Functions、DBテストの配置先として`supabase/migrations`、`supabase/functions`、`supabase/tests`を用意した。
- `supabase/seed.sql`を作成し、後続TODOで開発用シードを追加できる状態にした。
- npm scriptsへSupabaseローカル操作の入口を追加した。
- Docker Desktop起動後、`npm run db:status`でローカルSupabaseの起動状態を確認した。

## 補足

- `supabase_imgproxy_card-game-app`と`supabase_pooler_card-game-app`は停止中だが、M0-SB-02のDBマイグレーション基盤確認では必須ではない。
- ローカル開発環境の警告どおり、開発用サービスはネットワーク到達可能な状態で起動するため、公開ネットワークでは扱わない。
- `npm run db:reset`はローカルDBを初期化する操作のため、実データ投入前または明示確認後に実行する。
