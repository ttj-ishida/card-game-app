## メモ

- **テスト範囲** — 250 seed × 5 人数 = 1250 手番試行。全て ROUND_OVER 到達。カード保存則（36 枚）毎手番検査。スロー発生 0。
- **決定性** — 同一 seed + 同一人間操作 → `deepEqual` で完全一致。CPU 決定の再現性を保証。
- **結果保存** — `finishRound()` で HTTP POST 1 回、二重呼び出しで POST なし（idempotency）。
- **実機スモーク延期** — 2～6 人 × 昼夜の全組み合わせは M2-QA-03 実機確認時に同梱予定（自動テスト範囲は十分なため）。
