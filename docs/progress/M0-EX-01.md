## 実施内容

- `apps/mobile`へExpo SDK 57のTypeScriptプロジェクトを作成した。
- Android先行・横画面要件に合わせ、`orientation`を`landscape`へ設定した。
- 開発用Android packageとして`com.ttjishida.cardgameapp.dev`を設定した。
- mobileアプリに`typecheck` scriptを追加した。
- root `package.json`からmobileアプリを起動・Android起動・型チェックできるscriptを追加した。
- Expo SDK 57の公式ドキュメントを確認し、生成されたReact Native / React依存とSDK対応を確認した。

| 種別 | パス | 内容 |

| npm scripts | `apps/mobile/package.json` | `start`、`android`、`ios`、`web`、`typecheck` |

## 受入結果

| 確認項目 | 結果 | 証跡 |
