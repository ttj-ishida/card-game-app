# M4-EX-09 フレンド対戦の退出・CPU引継ぎ表示

## Status

Done（MVP）。

## Summary

サーバー側の `leave_friend_round`（M4-SB-12）は `PLAYER_LEFT_CPU_TAKEOVER` /
`PLAYER_FORFEITED` イベントを公開ログへ書き込む。クライアントはこれを表示に反映する:

- `apps/mobile/src/features/online-room/onlineRoundViewModel.ts`:
  - `OnlineRoundEventView` に生の `eventKind`（サーバーの `event_kind`）を追加。
  - `deriveSeatTakeovers(events)` を追加。イベントログから席ごとの離脱状態
    （`'CPU'` = CPU引き継ぎ / `'LEFT'` = 棄権）を導出する純関数。離脱イベントの
    `actor_player_id`（= `seatId`）が離脱した本人。
- `apps/mobile/src/app/online-room/play.tsx`:
  - 相手パネルに「CPU操作中」/「退出」タグを表示。
  - 履歴パネルで離脱イベントを「相手N · 退出（CPUが引き継ぎ）」等の行として表示。

`leave_friend_round` は退出者が残り1人になった場合 `winner_player_id` を返し、その
イベントで対局終了 → 既存の `extractWinnerId` が拾って勝敗バナーを出す（対応済み）。
