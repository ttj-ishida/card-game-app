## 概要

4属性フレームと紋章の本番候補のプレースホルダ SVG をプログラム生成で追加した（M1-GR 方式踏襲）。属性別の縁形状（火=棘 / 水=波 / 風=渦 / 土=菱）＋紋章シルエット。合成プレビューで代表3枚を比較可能。本番アートは M3-GR / M6 で差し替える。
