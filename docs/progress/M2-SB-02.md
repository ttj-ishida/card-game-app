## 概要

同じ端末での練習統計継続。`anonPlayerId` モジュール（端末固有ID の生成・永続化）で、初回起動時に UUID を生成し AsyncStorage へ保存。以後の対局は同じ ID で `practice_round_results` へ保存される。ID が端末に永続化され、再起動後も同じ ID で統計が続く。

## メモ

- **getAnonPlayerId** — 初回は `makeId()` で生成し `storage.setItem(ANON_PLAYER_ID_KEY, id)` で保存。以後の呼び出しは `storage.getItem()` で取得。プロセス内メモ化で重複保存を避ける。
- **エラーハンドリ** — `storage.getItem` / `setItem` が例外を投げても、`makeId()` の値を返し対局は続行。保存失敗は握りつぶす（ID がその起動限りになるが、対局自体は成功）。
- **配線** — ストア設定時に `makeId: () => Crypto.randomUUID()` を注入。テスト時はカウンター付きフェイク（`id-1`, `id-2`, ...）。
- **後続の統計画面** — M3-EX-05 でこの `anonPlayerId` を索引に `practice_round_results` を読む。M2 は保存のみ。
