# M3-EX-06: 初回チュートリアル

## 状態

完了。CPU戦設定から初回チュートリアルを開き、配布、提出、パス、昼夜、スキル効果を5ページで確認できる。

## 実装

- `apps/mobile/src/features/cpu-game/tutorialModel.ts`
  - チュートリアルページ定義、必須トピック網羅、ページindex境界、完了状態のparse/serializeを実装。
- `apps/mobile/src/state/cpuGameTutorialStore.ts`
  - AsyncStorageへ完了状態を保存する `load` / `complete` / `reset` を追加。
  - 保存失敗時は未完了状態を勝手に完了へ進めない。
- `apps/mobile/src/app/cpu-game/tutorial.tsx`
  - M3-GR-05の5枚のSVG図解を表示するページ送り画面を追加。
- `apps/mobile/src/app/cpu-game/setup.tsx` / `_layout.tsx`
  - CPU戦設定画面からチュートリアルへ移動できる導線とルートを追加。
- `apps/mobile/metro.config.js`
  - ルート `assets/` をMetroのwatch対象に追加し、M3図解SVGをAndroid exportへ含める。
