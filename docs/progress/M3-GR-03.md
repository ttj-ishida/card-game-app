# M3-GR-03: Joker系スキルカード候補

## 状態

完了。勇者Jokerと聖女Jokerのスキルカード候補SVGを生成した。

## 実装

- `scripts/generate-m3-graphics-assets.mjs`
  - `SKILL_JOKER_HERO` 用に太陽・剣のモチーフを生成。
  - `SKILL_JOKER_SAINT` 用に月・杯のモチーフを生成。
  - `assets/source/m3/skill-candidates/*.source.svg` と `assets/runtime/m3/skill-candidates/*.svg` に出力。
- `assets/manifests/m3-graphics-assets.json`
  - `skillCandidates` にJoker系2件を登録。

## 確認

- `npm run assets:generate:m3`
- `npm run assets:check:m3`

## 残り

- 本実装では、スキル選択UI上で説明文・使用済み状態・不可状態と並べて視認性を確認する。
