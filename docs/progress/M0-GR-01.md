# M0-GR-01 進捗

## 概要

M0のアートディレクション基準を、編集可能な1枚資料、runtime review asset、source manifestとして作成した。この方針により、M0カードカタログで使う仮素材の語彙を固定した。対象は、読みやすいカード表面、安定した属性シルエット、昼夜対応、明示的な禁止例である。

## 成果物

| 成果物 | path |
|---|---|
| アートディレクション1枚資料 | docs/art/M0-GR-01-art-direction.md |
| 編集可能な元素材 | assets/source/m0/art-direction-board.source.svg |
| runtime review asset | assets/runtime/m0/art-direction-board.svg |
| asset tracking manifest | assets/source-manifests/m0-gr-01-art-direction.json |

## 要件対応

| 要件 | 対応 |
|---|---|
| UI-A11Y-001 | 昼夜、属性、lock状態をicon、shape、label、patternでも区別する。 |
| UI-A11Y-002 | 火、水、風、土のsilhouetteを色とは別に定義した。 |
| UI-A11Y-003 | 小さな表示で読めるよう、短いlabelと大きなmarkを予約した。 |
| UI-LAYOUT-001 | review boardはAndroid横画面を前提にしている。 |
| FX-002 | 後続のrevolution state preview向けに昼夜palette方針を固定した。 |
| FX-003 | 属性lockは紋章とring/barrier表現を使う方針にした。 |
| DATA-M-001 / DATA-M-002 | asset trackingで安定IDと表示名非依存を維持する。 |
| FUT-006 | manifestにasset ID、version、source、runtime path、dimensions、licenseを記録した。 |
