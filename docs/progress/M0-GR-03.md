# M0-GR-03 進捗

## 概要

火、水、風、土の仮紋章と、M0の昼夜パレットを作成した。各属性には固有の形の手がかりを持たせ、色だけに頼らずcatalogで属性を識別できるようにした。

## 成果物

| 成果物 | path |
|---|---|
| 属性・palette仕様 | docs/art/M0-GR-03-suits-and-palettes.md |
| 属性・palette manifest | assets/manifests/m0-suits-and-palettes.json |
| 編集可能なemblem source | assets/source/m0/emblems/*.source.svg |
| runtime emblem asset | assets/runtime/m0/emblems/*.svg |
| 更新済みasset inspection | scripts/check-m0-assets.mjs |

## 確認結果

| 確認 | 結果 |
|---|---|

| 高重大度の既知不具合 | 0 |

## メモ

- assetはプロジェクト所有のplaceholderであり、第三者source materialを含まない。
- 4つのemblemは、M0 catalogの読みやすさとrepository reviewしやすさを優先して単純化している。
- M0-GR-04はM0-GR-02寸法と本属性assetを使って全カードplaceholderを生成できる。
