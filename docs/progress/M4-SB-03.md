# M4-SB-03: `round_public_state`と`round_events`を作る

状態: 完了
日付: 2026-09-04

## 概要

M4オンライン対局の公開状態と公開イベントログを保存できるようにした。

M3にCPU戦用の`round_events`が既に存在するため、M4オンライン用は`online_round_public_state`と`online_round_events`という実テーブル名にした。これにより、CPU戦の保存済み履歴とオンライン対戦の同期・再接続用ログを混同しない。

## 実装

- `supabase/migrations/20260904100000_create_online_public_state_and_events.sql`
  - `online_round_public_state`
    - `round_id`ごとの公開スナップショット。
    - `state_version`、`day_night`、`active_player_id`、`active_field`、`hand_counts`を保持する。
    - `active_field`と`hand_counts`はJSON objectに制限する。
  - `online_round_events`
    - `round_id`、`event_seq`、`state_version`、`event_kind`、`actor_player_id`、`public_payload`を保持する。
    - `(round_id, event_seq)`を主キーにする。
    - `public_payload`はJSON objectに制限する。
  - `public.is_round_member(round_id)`
    - RLSから呼ぶ参加者判定用の`security definer`関数。
  - 参加者だけSELECT可能なRLS policyを追加。
  - anonはSELECT不可、authenticatedのINSERT/UPDATE不可、service_roleは全権限。
- `supabase/tests/online_public_state_schema.sql`
  - テーブル、列、既定値、RLS、制約、公開状態とイベント保存を確認。
- `supabase/tests/online_public_state_access.sql`
  - 参加者が公開状態・公開イベントを読めること、非参加者とanonが読めないこと、authenticatedがイベントを直書きできないことを確認。

## 境界

- 公開状態には、場、昼夜、手番、手札枚数など全参加者へ見せてよい情報だけを入れる。
- 非公開手札、未使用スキル、山札順、秘密値は`online_round_public_state` / `online_round_events`へ入れない。
- Realtime subscription設定、イベント欠落検知、スナップショット再取得はM4-SB-09～10で扱う。
