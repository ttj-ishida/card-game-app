# M4-SB-10: 最新スナップショット取得と再接続処理

## 状態

完了。

## 実装内容

- 再接続・状態版不一致から復旧するためのRPC `get_friend_round_snapshot(round_id, after_state_version)` を追加した。
- RPCは認証済みの対局参加者だけが実行でき、未参加ユーザーにはスナップショットを返さない。
- 返却JSONに、公開状態、呼び出し本人の手札、呼び出し本人のスキル、イベントログ、最新状態版、最新イベント連番を含めた。
- `after_state_version` を指定した場合は、その状態版より後のイベントだけを返す。Realtimeイベントの欠落検知後に、クライアントが最新スナップショットへ戻れる前提を作った。
- DBテスト `online_round_snapshot.sql` を追加し、参加者権限、本人情報限定、イベント差分取得を検証した。
