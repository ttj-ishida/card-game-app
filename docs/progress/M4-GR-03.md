# M4-GR-03: 相手の裏向き手札とスキル保有表示

## 状態

完了。M4フレンド対戦αで、相手の非公開手札を表向きにせず、残り枚数帯とスキル保有状態を読み取れる粗SVG素材を追加した。

## 実装

- `scripts/generate-m4-room-ui-assets.mjs`
  - 相手の裏向き手札表示を3枚生成。
  - `LOW`、`MID`、`HIGH` の残り枚数帯を、カード束の枚数差とラベルで識別できるようにした。
  - 相手のスキル状態バッジを3枚生成。
  - `UNKNOWN`、`HELD`、`USED` を、色だけでなく記号とラベルでも識別できるようにした。
- `assets/manifests/m4-room-ui-assets.json`
  - `M4-GR-01` と同じM4 room UI manifestへ、`M4-GR-03`のasset ID、source/runtime path、状態ID、寸法、容量上限を追記。
- `assets/source/m4/room-ui/opponent-hand-backs/**`
  - 編集可能なsource SVG。
- `assets/runtime/m4/room-ui/opponent-hand-backs/**`
  - アプリ組み込み候補のruntime SVG。
- `assets/source/m4/room-ui/opponent-skill-badges/**`
  - 編集可能なsource SVG。
- `assets/runtime/m4/room-ui/opponent-skill-badges/**`
  - アプリ組み込み候補のruntime SVG。
- `scripts/check-m4-assets.mjs`
  - M4-GR-03の2カテゴリを検査対象に追加し、合計21 assets / 42 SVGを確認するようにした。

## 確認

| コマンド                     | 結果                         |
| ---------------------------- | ---------------------------- |
| `npm run assets:generate:m4` | PASS（21 assets生成）        |
| `npm run assets:check:m4`    | PASS（42 SVG files checked） |

## 残り

- M4-EX-04以降でオンライン公開状態をUIへ変換するとき、実際の残り枚数を `LOW` / `MID` / `HIGH` のどの帯へ丸めるかを最終決定する。
- M4-EX-04以降で、相手の未使用スキルを「枚数のみ見せる」のか「保有有無のみ見せる」のかを、サーバー公開状態の仕様に合わせて確定する。
