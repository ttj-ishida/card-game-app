# M3-EX-08: 演出短縮・軽量設定の土台

## 状態

完了。CPU戦設定を保存し、CPU思考待ち時間へ速度設定を反映できる。

## 実装

- `apps/mobile/src/features/cpu-game/cpuGameSettings.ts`
  - `animationSpeed` と `lowMotion` の v1 永続化形式を定義。
  - 壊れた保存値は初期値へ戻す。
  - CPU思考待ち時間の倍率を計算。
- `apps/mobile/src/state/cpuGameSettingsStore.ts`
  - AsyncStorage 依存を注入し、変更時に即保存。
  - 保存失敗時もメモリ上の選択は維持。
- `apps/mobile/src/state/cpuGameStore.ts`
  - `advanceCpu()` が設定 store の速度倍率を使う。
- `apps/mobile/src/app/cpu-game/settings.tsx`
  - 速度の選択と軽量表示トグルを提供。

## 確認

- `npx tsx --test src/features/cpu-game/cpuGameSettings.test.ts src/state/cpuGameSettingsStore.test.ts src/state/cpuGameStore.test.ts`
- `npm run mobile:test`
- `npm run mobile:typecheck`
- `npm run mobile:lint`
- `npm run mobile:format:check`
- `npm run mobile:export:android`

## 残り

- `lowMotion` は M3 では設定土台。重い演出の削減対象が増える M6 以降で個別演出へ反映する。
