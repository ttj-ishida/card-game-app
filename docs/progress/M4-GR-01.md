# M4-GR-01: ルーム・席・準備状態のUI素材

## 状態

完了。M4フレンド対戦αのルーム作成・待機画面で使える、2〜6人レイアウト、席役割、準備状態、接続状態の粗SVG素材を生成した。

## 実装

- `scripts/generate-m4-room-ui-assets.mjs`
  - 2〜6人の待機ルームレイアウトを5枚生成。
  - ホスト、ゲスト、空席、CPU引継ぎの席バッジを4枚生成。
  - 準備済み、待機中、ロック済みの準備状態バッジを3枚生成。
  - オンライン、接続中、オフラインの接続状態バッジを3枚生成。
- `assets/manifests/m4-room-ui-assets.json`
  - asset ID、source/runtime path、寸法、容量上限、TODO IDを追跡。
- `assets/source/m4/room-ui/**`
  - 編集可能なsource SVG。
- `assets/runtime/m4/room-ui/**`
  - アプリ組み込み候補のruntime SVG。
- `scripts/check-m4-assets.mjs`
  - manifestの網羅、SVG namespace、`role="img"`、`title`、`desc`、寸法、容量上限を検査。
- `package.json`
  - `assets:generate:m4`、`assets:check:m4` を追加。

## 確認

| コマンド                     | 結果                         |
| ---------------------------- | ---------------------------- |
| `npm run assets:generate:m4` | PASS（15 assets生成）        |
| `npm run assets:check:m4`    | PASS（30 SVG files checked） |
