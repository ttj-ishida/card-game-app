# M0-GR-04 進捗

## 概要

seed済みのすべての数字カードID、各スキル定義、共通カード裏面に対するM0 placeholder assetを生成した。manifestでは、36枚の数字カードと、skill card_countが表す6枚のスキルカードを合わせて、物理デッキ42枚を表現している。

## 成果物

| 成果物 | path |
|---|---|
| placeholder asset仕様 | docs/art/M0-GR-04-card-placeholders.md |
| placeholder manifest | assets/manifests/m0-card-placeholders.json |
| number placeholder source | assets/source/m0/cards/number/*.source.svg |
| number runtime placeholder | assets/runtime/m0/cards/number/*.svg |
| skill placeholder source | assets/source/m0/cards/skill/*.source.svg |
| skill runtime placeholder | assets/runtime/m0/cards/skill/*.svg |
| card back source/runtime | assets/source/m0/cards/back/card-back-m0.source.svg、assets/runtime/m0/cards/back/card-back-m0.svg |
| generator | scripts/generate-m0-card-placeholders.mjs |
| 更新済みasset inspection | scripts/check-m0-assets.mjs |

## メモ

- M0-GR-04はplaceholder artのみを作成する。カード名と長い説明文はlocalization resourceに置く。
- skillの重複枚数はartwork fileを複製せず、card_countで表現する。
- M0-QA-01は assets/manifests/m0-card-placeholders.json からruntime placeholder pathを取得し、Supabase master rowへ結合できる。
