# M0-QA-01 進捗

## 概要

mobile card catalogのdata flowを、Supabase master rowとM0 placeholder asset metadataへ接続した。アプリのcatalog routeは、Supabase RESTからpublicな number_cards と skill_cards を取得し、それらをlocal placeholder asset metadataと結合して42件のdisplay itemへ展開し、tap時に拡大表示を開ける。

## メモ

- Supabase accessは EXPO_PUBLIC_SUPABASE_ANON_KEY のpublic anon keyを使い、activeなpublic master rowだけを読む。
- pure catalog builderは、skill定義4件をcard_countで6つのphysical display itemへ展開し、36 + 6 = 42にする。
- React NativeでのSVG画像直接描画はM0-QA-01では導入しない。画面はnative placeholder cardと安定asset ID、runtime pathを表示する。
- fetch失敗時はerror stateへ移り、retry buttonを利用可能なままにする。
