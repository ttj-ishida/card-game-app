## 概要

対局終了後の結果画面。`resultModel` モジュール（型・ロジック）で `DriverState` → `RoundResultView`（勝者・勝敗・ターン数・時間）と `PracticeResultPayload`（DB 保存用）を導出。result.tsx が結果を表示し、「再戦」「ホームへ」ボタンを提供。`finishRound()` で `recordFinishedRound()` を呼んで結果を DB へ POST（または失敗時キュー投入）。

## メモ

- **RoundResultView** — `winnerSeatId` / `winnerNameKey` / `localWon`（自分が勝ったか）/ `playerCount` / `turnCount` / `durationMs`。画面が UI に。
- **PracticeResultPayload** — M2-SB-01 テーブル列に直接対応。`mode: 'CPU_PRACTICE'` / `player_count` / `local_player_seat`（常に 0）/ `winner_seat` / `local_won`（CHECK: `winner_seat === local_player_seat`） / `turn_count` / `duration_ms` / `round_seed`（決定性の為） / `client_result_id` / `anon_player_id`。
- **画面からの呼び出し** — `ROUND_OVER` フェーズで自動 replace → `/cpu-game/result` → ユーザーが「再戦」「ホームへ」をタップ → ストアアクション（`rematch()` / `exit()`）。`finishRound()` は結果画面到達時に1回だけ、非ブロッキング。
- **保存の成否** — 成功・失敗・二重登録をステータスで区別。失敗時はキュー投入し「後で再送します」表示。二重登録は `client_result_id` で防ぐ。
