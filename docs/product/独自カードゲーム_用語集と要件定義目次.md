# 独自カードゲーム 用語集・要件定義目次

- 文書状態：ドラフト
- 作成日：2026-08-27
- 対象：初期リリース版

## 1. 用語集

### 1.1 表記ルール

本書および今後の要件定義では、次の表記を使用する。

- カードに記載された1～9を「数字」と呼ぶ。内部設計で使う「ランク」と同義だが、画面・ルール説明では「数字」に統一する。
- 火・水・風・土を「属性」と呼ぶ。「スート」と同義だが、画面・ルール説明では「属性」に統一する。
- 「ロック」だけでは意味が曖昧になるため、必ず「場のロック」（枚数ロック / 属性固定ロック / 属性統一ロックの総称）または「追加封印」と記載する。個別のロックを指すときはその名称を用いる。
- 1回の配布から勝者決定までを「1局」と呼ぶ。
- 「カードを出す」は、数字カードやスキルカードを選択して確定する一連の操作を指す。

### 1.2 ゲーム・対戦単位

| 用語 | 定義 |
|---|---|
| ゲーム | 本カードゲームのサービス全体。 |
| プレイヤー | 対局に参加する人間またはCPU。 |
| アクティブプレイヤー | 棄権しておらず、現在の局に参加し続けているプレイヤー。 |
| 1局 | カードの配布から、勝者決定または対局終了までの単位。 |
| 再戦 | 同じルームの参加者で、新しくカードを配り直して次の局を始めること。 |
| ルーム | プレイヤーが集合し、1局以上の対局を行う単位。 |
| CPU戦 | 人間プレイヤーがCPUを相手に行う練習用対戦。公式勝利数には加算しない。 |
| フレンド対戦 | 合言葉などで参加者を限定する対戦。勝利数はルーム内で集計し、公式勝利数には加算しない。 |
| 公式ランダム対戦 | ランダムマッチングされた人間4人で行う公式対戦。勝者に公式勝利数を1加算する。 |
| カジュアル対戦 | 公式勝利数の対象外として遊ぶオンライン対戦。詳細は要件定義で決定する。 |
| 先攻 | 1局の開始時に、最初の場を作るプレイヤー。 |
| 先頭 | 場が空になった後、新しい場を作るプレイヤー。先攻を含む上位概念。 |
| 手番 | 1人のプレイヤーが、カードを出すかパスするための操作機会。 |
| 手番順 | プレイヤーへ順番に手番を割り当てる順序。昼夜が反転しても手番順は変わらない。 |
| 最終出し手 | 現在の場に最後にカードを出したプレイヤー。通常の場流し後は、このプレイヤーが次の先頭になる。 |

### 1.3 カード構成

| 用語 | 定義 |
|---|---|
| 数字カード | 1～9の数字と、火・水・風・土のいずれかの属性を持つカード。全36枚。 |
| 数字 | 数字カードの強さを比較する1～9の値。昼と夜で強弱が反転する。 |
| 属性 | 数字カードが持つ火・水・風・土の分類。属性固定ロック・属性統一ロックの判定に使用する。 |
| 数字デッキ | 36枚の数字カード全体。各局の開始時にすべて配る。 |
| スキルカード | 通常の数字比較とは異なる効果を発生させる使い切りカード。数字カードとは別枠で所持する。 |
| スキルデッキ | 初期版では、勇者Joker1枚、聖女Joker1枚、追加封印2枚、革命2枚の計6枚。 |
| スキル枠 | 数字カードの手札と分けて、配布されたスキルカード1枚を保持する領域。 |
| Joker | 勇者Jokerと聖女Jokerの総称。場流しまたはカードへの変化を選択できるスキルカード。 |
| 勇者Joker | Jokerの1枚。初期版では聖女Jokerと同じルール上の効果を持つ。 |
| 聖女Joker | Jokerの1枚。初期版では勇者Jokerと同じルール上の効果を持つ。 |
| 追加封印カード | 数字カードと同時に使用し、以降の同数字追加と連番拡張を禁止するスキルカード。従来の呼称「ロックカード」は使用しない。 |
| 革命カード | 数字カードと同時に使用し、先に昼夜を反転してから、その数字カードの合法性を判定するスキルカード。 |
| 公開効果 | 相手の非公開カードを一時的に見られるようにする将来拡張用の効果。「カードオープン」などを想定する。 |
| 手札 | プレイヤーが所持する数字カード。スキルカードは手札に含めず、スキル枠として区別する。 |
| 残り枚数 | プレイヤーの手札に残っている数字カードの枚数。全員に公開する。 |
| 未配布スキル | 参加人数が6人未満の場合に、誰にも配られなかったスキルカード。対局中は公開しない。 |
| 捨て札 | 場の更新または場流しによって、アクティブセットから取り除かれた使用済みカード。 |

### 1.4 場とカード操作

| 用語 | 定義 |
|---|---|
| 場 | 現在のカード比較と効果判定の対象となる領域。 |
| 場が空 | 比較対象となるアクティブセットが存在しない状態。この状態ではパスできない。 |
| アクティブセット | 現在の場で有効な、1枚以上のカードの組み合わせ全体。単体、同数セット、連番セットのいずれか。 |
| カードを出す | 選択したカードと宣言内容をサーバーへ送信し、合法性の判定後に場へ反映すること。 |
| リード | 場が空の状態で、先頭プレイヤーが新しいアクティブセットを作ること。 |
| 追加 | 現在のアクティブセットを残し、同じ数字または連続する数字を継ぎ足して枚数を増やすこと。 |
| 同数字追加 | 同数セットに、同じ数字のカードを1枚以上追加すること。通常カードとJokerを合わせても最大4枚。 |
| 連番拡張 | 連番セットの端へ、連続する数字を1枚以上まとめて追加すること。昼は大きい数字側、夜は小さい数字側へ追加する。 |
| 更新 | 現在のアクティブセットを捨て札へ移し、同じ種類・同じ枚数の、より強い組み合わせへ置き換えること。 |
| パス | カードを出さずに次のプレイヤーへ手番を渡すこと。場が空のときは選択できない。 |
| 連続パス | 最終出し手の後に、ほかのアクティブプレイヤーが続けてパスしている状態。誰かがカードを出すとリセットする。 |
| 場流し | 現在のアクティブセットを捨て札へ移し、場を空にすること。通常の場流しとJokerによる場流しがある。 |
| 通常の場流し | 最終出し手以外の全アクティブプレイヤーが、その後連続してパスした場合に発生する場流し。 |
| Jokerによる場流し | 場があるときにJokerを単体で使用し、直ちに場を流すこと。使用者は同じ手番内で新しい場を作る。 |
| 宣言 | 変化Jokerに割り当てる数字と属性を選択して確定すること。 |
| 対局履歴 | 誰が、いつ、どのカードやスキルを使用したかを確認できる公開記録。流れたカードも確認できる。 |

### 1.5 カードの組み合わせと比較

| 用語 | 定義 |
|---|---|
| 単体 | 1枚で構成されるアクティブセット。 |
| 同数セット | 同じ数字のカード2～4枚で構成する組み合わせ。属性は重複できない。 |
| 連番セット | 連続する異なる数字3枚以上で構成する組み合わせ。数字1～9の範囲で循環しない。 |
| 組み合わせ種別 | 単体、同数セット、連番セットの分類。場の更新時に別の種別へ変更できない。 |
| 同枚数条件 | 場を更新するとき、現在のアクティブセットと同じ枚数を出さなければならない条件。 |
| 強い組み合わせ | 現在の昼夜状態に従い、場の組み合わせより強い数字で構成された、同じ種別・同じ枚数の組み合わせ。 |
| 合法プレイ | 数字、枚数、種類、場のロック（枚数 / 属性固定 / 属性統一）、追加封印、昼夜、スキル効果、Joker宣言をすべて満たすカードの出し方。 |
| 不正プレイ | いずれかのルールを満たさないカードの出し方。カードと効果は消費せず、状態を変更しない。 |
| 完全重複 | 数字と属性の両方が同じカードが、同じアクティブセット内に複数存在する状態。実在カードと変化Jokerの間も含めて禁止する。 |

### 1.6 昼夜・ロック・革命

| 用語 | 定義 |
|---|---|
| 昼 | 数字が大きいほど強い状態。強さは1から9へ向かって上昇する。各局は昼から開始する。 |
| 夜 | 数字が小さいほど強い状態。強さは9から1へ向かって上昇する。 |
| 昼夜状態 | 現在が昼か夜かを表す対局全体の状態。通常の場流しでは変化しない。 |
| 革命 | 昼と夜を反転させ、数字の強弱と連番の拡張方向を切り替えること。 |
| 自然革命 | 4枚以上の新しい組み合わせを出すか、3枚以下の組み合わせを追加によって4枚以上にしたとき発生する革命。 |
| 再革命 | 新しい4枚以上の組み合わせで場を更新し、再び昼夜を反転させること。 |
| 革命対象外の拡張 | すでに4枚以上ある連番セットへ追加すること。この追加だけでは自然革命を発生させない。 |
| スキル革命 | 革命カードによって発生する革命。数字カードの合法性を判定する前に昼夜を反転する。 |
| 自然革命との併用禁止 | 自然革命が発生するカードの出し方と革命カードを同時に使用できない制約。 |
| 場のロック | 枚数ロック・属性固定ロック・属性統一ロックの総称（旧版で単に「属性ロック」と呼んでいた概念を含む）。詳細は要件定義書 §10.1。 |
| 枚数ロック | アクティブセットが一度でも更新されると発生。以降は追加・拡張を認めず、更新直前と同じ枚数・同じ種別のより強い組み合わせによる更新のみ可。 |
| 属性固定ロック | 初回更新で出したカードの属性の組が、置き換えるセットの属性の組と多重集合一致した場合に発生。以降の更新は属性の組が一致すること。初回不一致なら発生しない。 |
| 属性統一ロック | 全カード同一属性の連番セットをリードしたとき発生。以降、追加は同一属性維持、更新は全カード同一属性の連番（属性は変更可）。 |
| 追加封印 | 追加封印カードによって発生し、同数字追加と連番拡張を禁止する場の効果。より強い同種・同枚数の組み合わせによる更新は可能。 |
| 場の継続効果 | 場のロック（3種）と追加封印の総称。場が更新されても継続し、場が流れたときに解除する。 |

### 1.7 Joker関連

| 用語 | 定義 |
|---|---|
| 変化Joker | 数字1～9と属性を宣言し、そのカードとしてアクティブセットへ参加させるJokerの使用方法。 |
| Joker宣言状態 | 変化Jokerへ割り当てた数字と属性。場が流れるまで変更できない。 |
| Jokerの複数参加 | 勇者Jokerと聖女Jokerを同じアクティブセットへ含めること。完全重複しない別のカードとして宣言する場合に認める。 |
| 変化Joker上がり | 最後の数字カードと変化Jokerを組み合わせて手札を0枚にする出し方。禁止する。 |
| 場流し後の上がり | Jokerで場を流した後、同じプレイヤーが最後の数字カードを出して上がること。認める。 |

### 1.8 スキルと効果処理

| 用語 | 定義 |
|---|---|
| スキル使用 | 自分の手番にスキルカード1枚を使用すること。Joker以外は数字カードと同時に使用する。 |
| 使い切り | 使用したスキルカードを捨て札へ移し、その局では再使用できないこと。 |
| 効果処理順 | 宣言、スキル革命、合法性判定、場への反映、追加封印、場のロック（枚数 / 属性固定 / 属性統一）、自然革命、勝利判定の順序。 |
| 全体判定 | 選択したカードとすべての効果を一つの操作として検証すること。途中で不成立なら全処理を取り消す。 |
| ロールバック | 不正プレイのとき、仮の昼夜反転を含む変更をすべて元へ戻し、カードを消費しない処理。 |
| 次手番から有効 | 追加封印が、それを使用した今回のカード提出には影響せず、次のプレイヤーから有効になること。 |

### 1.9 勝利・記録・順位

| 用語 | 定義 |
|---|---|
| 上がり | 合法なプレイを完了した結果、数字カードの手札が0枚になること。スキル枠にカードが残っていてもよい。 |
| 勝者 | 最初に上がったプレイヤー。勝者決定時にその局を直ちに終了し、2位以下は決めない。 |
| スキル併用上がり | 最後の数字カードと追加封印カードまたは革命カードを同時に使用して上がること。認める。 |
| 自然革命上がり | 最後の数字カードによる組み合わせで自然革命を発生させて上がること。認める。 |
| 勝利数 | 勝者になった局の累計。1局につき勝者だけへ1加算する。 |
| ルーム内勝利数 | 同じルーム内で再戦した結果を集計した勝利数。 |
| 公式勝利数 | 公式ランダム対戦で獲得した勝利数。公式順位の唯一の判定基準。 |
| 通算対局数 | 対象モードで最後まで記録された局の累計。モード別に保持する。 |
| 勝率 | 勝利数を通算対局数で割った参考値。公式順位の同率判定には使わない。 |
| 同順位 | 公式勝利数が同じ複数プレイヤーを同じ順位として扱うこと。 |

### 1.10 公開・非公開情報

| 用語 | 定義 |
|---|---|
| 公開情報 | 全プレイヤーが確認できる情報。場のカード、使用済みカード、残り枚数、使用済みスキル、昼夜、ロック状態など。 |
| 非公開情報 | 原則として所有者だけが確認できる情報。手札の内容と未使用スキルの種類。 |
| スキル保有表示 | 相手が未使用スキルを1枚持っていることだけを示す表示。種類は公開しない。 |
| スキル公開 | スキルを使用した時点で、種類と効果を全員へ表示すること。 |
| 未使用スキル非公開 | 勝者決定時に未使用だったスキルの種類を、対局終了後も公開しないこと。 |

### 1.11 時間切れ・通信切断

| 用語 | 定義 |
|---|---|
| 手番制限時間 | 公式対戦でカード選択に使える30秒。操作可能になった時点から計測し、残り10秒で警告する。 |
| 時間切れ | 手番制限時間内に合法な操作を確定できなかった状態。 |
| 自動パス | 場がある状態で時間切れになったとき、システムがパスを確定する処理。 |
| 自動提出 | 場が空の状態で時間切れになったとき、現在の昼夜で最も弱い数字カード1枚をシステムが出す処理。 |
| 再接続猶予 | 通信切断後、棄権とせず復帰を待つ60秒間。対局自体は停止しない。 |
| 棄権 | 明示的な退出、60秒を超える通信切断、または3回連続の時間切れにより、その局から離脱すること。 |
| 棄権者の手札除外 | 棄権者が所持する未使用カードを対局から取り除く処理。棄権前に場へ出したカードは場が流れるまで有効。 |
| CPU引継ぎ | フレンド対戦で、棄権したプレイヤーの席をCPUが引き継ぐ任意設定。公式対戦では使用しない。 |

## 3. 目次の利用方針

- 第6～14章をゲームルールの正本とする。
- 第13章で処理順と状態遷移を定義し、各ルールの重複記述を避ける。
- 第25～26章で、クライアント表示とサーバー上の正しい状態を分離して定義する。
- 初期版に含めない項目も削除せず、「対象外」または「将来拡張」と明記する。
- 各要件には要件ID、優先度、根拠、受入条件を付け、テスト項目へ追跡できるようにする。
