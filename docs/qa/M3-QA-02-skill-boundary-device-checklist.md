# M3-QA-02: 全スキルと全上がり境界の実機確認チェックリスト

日付: 2026-09-02
状態: 実機確認待ち（自動準備完了）

## 目的

M3-QA-02 は、実機または Android エミュレーター上で人間プレイヤーのスキル UI と上がり境界を確認する QA タスクである。`game-core` と `apps/mobile` の自動テストではルール判定とストア状態遷移を確認済みだが、画面操作・表示更新・保存後の導線は端末上で観測する必要がある。

## 実施前提

1. リポジトリルートで `npm run qa:m3:preflight` が PASS している。
2. Supabase local が必要な場合は `npm run db:start` 済みで、`apps/mobile/.env.local` に `EXPO_PUBLIC_SUPABASE_URL` と `EXPO_PUBLIC_SUPABASE_ANON_KEY`（または Publishable key）が設定されている。
3. Android 実機またはエミュレーターで `npm run android` を起動できる。
4. 確認中に不具合が出た場合は、端末名、OS、対局人数、シード表示または再現手順、表示メッセージ、スクリーンショット有無を記録する。
