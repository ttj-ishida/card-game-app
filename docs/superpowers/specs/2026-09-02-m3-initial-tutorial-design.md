# M3-EX-06 初回チュートリアル 設計書

- 作成日: 2026-09-02
- 対象 TODO: M3-EX-06
- 依存: M3-GR-05

## 目的

CPU戦の初回導線で、配布、提出、パス、昼夜、スキル効果を短いページ型チュートリアルとして説明できるようにする。M3-GR-05で生成した図解SVGをページに対応付け、完了状態は端末ローカルに保存する。

## 範囲

- `/cpu-game/tutorial` 画面を追加する。
- CPU戦設定画面にチュートリアル導線を追加する。
- チュートリアル完了状態を AsyncStorage に保存する。
- ページ定義、必須トピック網羅、保存形式は純モジュールでテストする。

## 対象外

- 強制的な初回ブロック。外部テストの邪魔にならないよう、未完了でもCPU戦は開始できる。
- チュートリアル完了率のサーバー送信。分析基盤は後続マイルストーンで扱う。
- 本番アート差し替え。M3では追跡可能なラフSVGを使う。

## 画面仕様

- CPU戦設定画面のメニューに「チュートリアル」を追加する。
- 未完了時は「初回おすすめ」として案内文を表示する。
- チュートリアル画面は5ページ構成にする。
  - 配布と目的
  - 提出と場の更新
  - パスと場流し
  - 昼夜の強弱
  - スキル効果
- 最終ページの完了ボタンで保存し、CPU戦設定へ戻る。
- 保存失敗時は失敗表示を出し、ページ操作は継続できる。

## データ仕様

- storage key: `card-game-app:cpu-game-tutorial:v1`
- 保存形式: `{ "completed": true, "completedAt": "ISO-8601" }`
- 不正JSON、欠損、不正型は未完了として扱う。
